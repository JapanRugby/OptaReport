App Folder権限のアプリなら、そのアプリフォルダ内の相対パスを指定します。ルートは空欄です。

1300件以上ある場合は、まず「差分キャッシュ + 並列」を推奨します。初回のみ時間がかかりますが、次回以降は変更されたCSVだけ取得します。

Dropbox App Consoleで必要な設定
  1. Dropbox APIアプリを作成
  2. 既存の通常フォルダを読むなら Full Dropbox、アプリ専用フォルダでよければ App Folder
  3. Permissionsで files.metadata.read と files.content.read を有効化
  4. Redirect URIに下記を完全一致で登録

file:// で直接開くとOAuthリダイレクトに使えない場合があります。GitHub PagesなどのHTTPS、またはローカルHTTPサーバーで開いてください。

v7: Tackle関連指標を Opta の Tackle Order / Qualifier5 に基づき、初期設定で 1st Tackler のみに限定しました。

集計設定

Tackle Attempt / Completion% / Dominance% はこの設定に従います。1st Tacklerのみの場合、action ID 2 / Tackle のうち Qualifier5 が 1st Tackler の行だけを集計します。

Opta定義では action=2 の Missed がタックル失敗です。1st Tackler限定時は action=2 かつ Qualifier5=708 の Missed も分母に含まれます。Missed Tackle actionはQualifier5を持たないことが多いため、通常は追加しない方が安全です。

Opta定義メモ
  • Playing Minutes: action ID 41 = Sub Out / Player Leaves Field、action ID 42 = Sub In / Player Enters Field から算出します。
  • Tackle Attempt: 初期設定では action ID 2 / actionName = Tackle のうち、qualifier5Name = 1st Tackler / qualifier5 = 708 のみを分母にします。
  • Tackle Dominance%: 1st Tacklerに限定したTackle Attemptのうち、qualifier4Name = Dominant Tackle の割合です。
  • Carry Dominance%: qualifier4Name = Dominant Contact ÷ Carry Attempt。
  • Post Contact Metres: Carryの Metres4。Opta定義では、最初のタックラーとの接触からキャリー終了までの距離です。
  • Attack Ruck OOA: action ID 43 / Ruck OOA かつ qualifier4Name = Attacking OOA。成功は初期設定で Secured / Cleaned Out。
  • Jackal: qualifier5Name = Jackal Attempt を試行、ActionTypeName = Penalty Won / Turnover Won を成功として集計します。
