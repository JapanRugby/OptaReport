Rugby Dropbox CSV Player Report v3

Dropboxフォルダ内のCSVを高速取得し、選手別のCarry数・Tackle成功率を集計します。

Dropboxフォルダ自動読み込み

初回だけDropbox認証が必要です。認証後は、このブラウザに保存された設定でページ表示時にフォルダ内CSVを自動集計します。

Dropbox接続状態を確認中...

App Folder権限のアプリなら、そのアプリフォルダ内の相対パスを指定します。ルートは空欄です。

1300件以上ある場合は、まず「差分キャッシュ + 並列」を推奨します。初回のみ時間がかかりますが、次回以降は変更されたCSVだけ取得します。

Dropbox App Consoleで必要な設定
  1. Dropbox APIアプリを作成
  2. 既存の通常フォルダを読むなら Full Dropbox、アプリ専用フォルダでよければ App Folder
  3. Permissionsで files.metadata.read と files.content.read を有効化
  4. Redirect URIに下記を完全一致で登録

file:// で直接開くとOAuthリダイレクトに使えない場合があります。GitHub PagesなどのHTTPS、またはローカルHTTPサーバーで開いてください。

v3: 1300件以上のCSVに対応するため、並列ダウンロード・ファイルrev別の差分キャッシュ・ZIP一括読み込みを追加しました。

集計設定

サンプルCSVでは Tackle / Missed と Missed Tackle が対応しているため、通常は追加しない方が安全です。
